# Keyword research provider options

Verified against first-party pages on **2026-09-06**. Provider limits, trials, prices, and whether a result is shown without an account can change without notice. Treat this as routing guidance, then check the linked provider page at run time before promising access or a quota.

## Paid options

Offer payment as a choice, never as a requirement. If the user declines, continue down the free-first order instead of stopping SEO research.

1. **Semrush SEO Toolkit** — strong default when the user already uses Semrush. Keyword Overview and Keyword Magic Tool provide volume and organic KD; paid plans materially increase daily requests and rows. [Keyword Overview metrics](https://www.semrush.com/kb/257-keyword-overview) · [plans and limits](https://www.semrush.com/kb/1547-seo-toolkit-pricing-and-plans)
2. **Ubersuggest** — provides search volume, SEO Difficulty, keyword ideas, and SERP data, with higher limits on paid plans. [Keyword tool](https://app.neilpatel.com/en/ubersuggest/keyword_ideas) · [pricing](https://app.neilpatel.com/pricing)
3. **Ahrefs Keywords Explorer** — provides country and global volume, organic KD, clicks, traffic potential, and SERP metrics. [Official product walkthrough](https://ahrefs.com/academy/how-to-use-ahrefs/keywords-explorer/overview) · [pricing](https://ahrefs.com/pricing)
4. **SE Ranking** — provides volume, organic difficulty, intent, current SERPs, and historical SERP data. Its trial is a useful bridge before payment. [Keyword tool](https://seranking.com/keyword-suggestion-tool.html) · [pricing](https://seranking.com/subscription.html)
5. **Mangools KWFinder** — provides exact-volume estimates, organic KD, trends, intent, and SERP analysis in a simpler workflow. [Search-volume and metric details](https://mangools.com/kwfinder/features/search-volume/) · [pricing](https://mangools.com/plans?service=kwfinder)

## Supplemental option

**Google Keyword Planner** provides estimated average monthly searches, but its `Competition` field measures advertiser competition rather than organic ranking difficulty. It cannot pass the provider gate by itself. Use it only to supplement a gate-passing provider, and do not describe it as anonymous or friction-free because Google requires account setup, including billing information, for basic keyword-idea access. [Official usage guide](https://support.google.com/google-ads/answer/7337243) · [metric definitions](https://support.google.com/google-ads/answer/3022575) · [access note](https://support.google.com/google-ads/answer/6325025)

## Routing rule for the skill

When a provider blocks further use:

1. If signing in unlocks documented free usage, say that plainly and ask the user to sign in.
2. Also say that a paid plan is available; link to the live official pricing page and avoid pressure.
3. If the user will not sign in, will not pay, or the allowance remains exhausted, move to the next free provider automatically. Do not keep asking about the rejected option.
4. Require both demand and organic difficulty from the provider that passes the gate. A demand-only tool may supplement the record but cannot win a keyword or replace the current SERP inspection; never relabel paid-ad competition as organic difficulty.
5. Record the provider, access tier, location/database, metric date when shown, demand value, organic-difficulty value or `unavailable`, and the date the live SERP was inspected.
