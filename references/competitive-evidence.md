## Matched evaluation

Use identical briefs, source exports, voice samples, tool access, model settings, and budgets. Compare each skill within its advertised scope; additionally compare a reasonable composed baseline for the full workflow. Run multiple trials and disclose the number.

Measure elapsed time, provider/browser calls, cost where observable, unsupported claims, lost claims, locale/window mistakes, author corrections, and publication-setting errors. Use blinded human review for voice; do not substitute a model's self-score.

Use a simulated editor for publication-setting cases. A live publication needs separate authorization. Report missing tools and failed trials. Do not convert quality checks into ranking or conversion forecasts. Conversion requires a subsequent observed campaign.
